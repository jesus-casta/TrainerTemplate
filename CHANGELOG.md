# Historial de versiones

## 0.1.0

Primera base ejecutable: Spring Boot, API autenticada, catálogo inicial editable, programas y series, referencias de carga, progresión básica, programación por fecha y vuelta, registro de RPE por serie, distribución de trabajo y exportación JSON. Persistencia H2 o PostgreSQL, Docker Compose y CI.

Las funciones completas de entrenador, IA, importación de hojas y análisis avanzado permanecen en el alcance del proyecto. Véase la matriz de requisitos.
